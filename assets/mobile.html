走不稳或发抖

先停止移动并扶稳小鸭。

  1. 检查舵机安装

    卸力后按编号图核对每个舵机的 ID、安装位置和顺序。检查舵盘和固定螺丝是否松动。

  2. 打开标定

    先标定 IMU，再按参考图重新标定全部 15 个舵机。

  3. 打开舵机设置

    扫描所有 ID，逐个写入 KP 5、KD 10，再读取核对保存值和运行值。断电重启后会加载保存值。

开机自启与唤醒

首次按 README 完成初始化，并在 App Lab 成功 Run 一次后，后续通电会自动启动网页、聊天和运动服务，无需每次再点 Run。

完成配网、账号绑定并接好 USB 音频设备后，启动就绪会依次播放两段鸭叫：

① 联网成功第一段鸭叫
② 语音服务就绪第二段鸭叫

试听在当前手机或电脑播放；开机提示音由小鸭扬声器播放。

听到两段启动提示音后，说当前选区的唤醒词。听到唤醒鸭叫后就可以说话了。

切换服务器会重新连接语音服务，两边的账号、设备绑定和智能体独立；对话语言、音量及运动设置保持。

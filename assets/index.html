Motion

Unsteady walking?

If Duck shakes or walks unsteadily, stop moving and support it.

  1. Check servo installation

    Release servo torque, then check each servo's ID, mounting position and order against the diagrams. Check the servo horns and retaining screws for looseness.

  2. Open Calibration

    Recalibrate the IMU first, then use the reference images to recalibrate all 15 servos.

  3. Open Servo setup

    Scan all IDs. Set KP to 5 and KD to 10 on each servo, then read back the saved and runtime values. Power-cycling reloads the saved values.
